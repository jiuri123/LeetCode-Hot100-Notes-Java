# 33. 搜索旋转排序数组

[https://leetcode.cn/problems/search-in-rotated-sorted-array/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/search-in-rotated-sorted-array/description/?envType=study-plan-v2&envId=top-100-liked)

```java
// 方法一：先判断左半段是否有序（推荐）
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return -1;
        }

        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            // 防止溢出的中点写法
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // 情况 1：左半部分是有序的
            if (nums[left] <= nums[mid]) { // 必须加等号
                // 判断 target 是否在左半部分范围内
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1; // 落在左边
                } else {
                    left = mid + 1;  // 落在右边
                }
            } 
            // 情况 2：右半部分是有序的
            else {
                // 判断 target 是否在右半部分范围内
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;  // 落在右边
                } else {
                    right = mid - 1; // 落在左边
                }
            }
        }

        return -1;
    }
}
```

```java
// 方法二：先判断右半段是否有序（有等号）
class Solution {
    public int search(int[] nums, int target) {
        if (nums == null || nums.length == 0) return -1;

        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // 先判断右半段是否有序
            if (nums[mid] <= nums[right]) { // 加不加等号都对
                // target 确实在右半段的范围内
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1; 
                } else {
                    right = mid - 1;
                }
            } 
            // 否则左半段一定是有序的
            else {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }
        }

        return -1;
    }
}
```

为什么方法一必须加等号，而方法二加不加等号都无所谓？

- 因为mid是向下取整，也就是说方法一的left和mid是有可能相等的，考虑两个元素的情况下，left和mid相等说明这时候左半段只有一个元素，而一个元素默认就是有序的。若不取等号，会将左半段的一个元素的情况判断成无序而跳过左半段的查找逻辑，造成错误。所以方法一必须加等号。
- 而方法二虽然也可能出现mid和right相等，但是这种情况只可能出现在只有一个元素的情况，而只有一个元素的情况下加不加等号都无所谓，因为if (nums[mid] == target) {return mid;}这段代码已经对这个元素做了判断，后面的代码有可能都走不到。即使走到了，也是为了调整right或left的值来跳出while循环。
