# 240. 搜索二维矩阵 II

[https://leetcode.cn/problems/search-a-2d-matrix-ii/submissions/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/search-a-2d-matrix-ii/submissions/?envType=study-plan-v2&envId=top-100-liked)

将矩阵逆时针旋转45度后，将其看成一颗类二叉树，根节点为原矩阵中右上角的那个数。由于题目所描述的矩阵特性，该类二叉树具有搜索二叉树的特性，即节点左边的值都比自己小，右边的值都比自己大。因此可以使用搜索二叉树的搜索算法去查找目标值。代码如下：

```java
// 时间复杂度：O(M+N)，M和N分别为矩阵的行和列，因为最多就只会遍历M+N个元素
// 空间复杂度：O(1)
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
			  // 边界条件处理
		    if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }
        int row =  matrix.length; // 行数
        int column = matrix[0].length; // 列数

        // 将矩阵逆时针旋转45度之后，将其看成一颗二叉树
        // 并设原矩阵右上角的点为根节点
        int i = 0;
        int j = column - 1;

        // 该二叉树与搜索二叉树性质相似，因此直接用二叉搜索树的查找算法
        while(i <= row - 1 && j >= 0){
            if(matrix[i][j] == target){
                return true;
            }else if(matrix[i][j] > target){
                j--; // 往左走
            }else{
                i++; // 往右走
            }
        }

        // 没找到
        return false;
    }
}
```
