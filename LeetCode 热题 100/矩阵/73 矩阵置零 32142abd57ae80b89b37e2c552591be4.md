# 73. 矩阵置零

[https://leetcode.cn/problems/set-matrix-zeroes/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/set-matrix-zeroes/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

```java
// 方法一（面试推荐）
// 时间复杂度：O(mn)
// 空间复杂度：O(1)
class Solution {
    public void setZeroes(int[][] matrix) {
        boolean isFirstRowContainZero = false;
        boolean isFirstColumnContainZero = false;

        // 下面两者的取值不要搞反了
        // 看题目示例就理解了：[[1,1,1],[1,0,1],[1,1,1]]
        int row = matrix.length; // 行数
        int column = matrix[0].length; // 列数

        // 检查第一列是否有 0
        // 这是使用行数row，则应该计算的是第一列
        for(int i = 0; i < row; i++){
            if(matrix[i][0] == 0){
                isFirstRowContainZero = true;
            }
        }

				// 检查第一行是否有 0
        // 这是使用列数column，则应该计算的是第一行
        for(int i = 0; i < column; i++){
            if(matrix[0][i] == 0){
                isFirstColumnContainZero = true;
            }
        }

        // 使用第一行和第一列来标记剩余部分中 0 的出现情况
        for(int i = 1; i < row; i++){
            for(int j = 1; j < column; j++){
                if(matrix[i][j] == 0){
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 根据第一行和第一列的标记，将对应的格点置 0
        for(int i = 1; i < row; i++){
            for(int j = 1; j < column; j++){
                if(matrix[i][0] == 0 || matrix[0][j] == 0){
                    matrix[i][j] = 0;
                }
            }
        }

        // 单独处理第一列的元素
        if(isFirstRowContainZero == true){
            for(int i = 0; i < row; i++){
                matrix[i][0] = 0;
            }
        }

        // 单独处理第一行的元素
        if(isFirstColumnContainZero == true){
            for(int i = 0; i < column; i++){
                matrix[0][i] = 0;
            }
        }
    }
}
```
