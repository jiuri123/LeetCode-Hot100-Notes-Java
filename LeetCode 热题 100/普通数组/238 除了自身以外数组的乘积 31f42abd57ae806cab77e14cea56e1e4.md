# 238. 除了自身以外数组的乘积

[https://leetcode.cn/problems/product-of-array-except-self/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/product-of-array-except-self/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：前缀积

定义两个数组分别计算原数组的左右前缀积（类似于前缀和的概念），然后遍历原数组，将当前位置的左前缀积和右前缀积相乘就等于数组中除了当前元素之外其余各元素的乘积 。整体代码如下：

```
// 方法一：前缀积
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;

        // 计算左前缀积（类似前缀和的概念）
        int[] leftMulti = new int[n];
        leftMulti[0] = nums[0];
        for(int i = 1; i < n; i++){
            leftMulti[i] = leftMulti[i - 1] * nums[i];
        }

        // 计算右前缀积
        int[] rightMulti = new int[n];
        rightMulti[n - 1] = nums[n - 1];
        for(int i = n - 2; i >= 0; i--){
            rightMulti[i] = rightMulti[i + 1] * nums[i];
        }

        // 左前缀积 * 右前缀积 = 数组中除当前元素外其余各元素的乘积
        int[] answer = new int[n];
        answer[0] = rightMulti[1];
        answer[n - 1] = leftMulti[n - 2];
        for(int i = 1; i < n - 1; i++){
            answer[i] = leftMulti[i - 1] * rightMulti[i + 1];
        }

        return answer;
    }
}
```

时间复杂度O(n)，空间复杂度O(n)。

## 方法二：方法一的空间优化

方法一的空间复杂度可以继续优化，即直接使用answer数组（题中说该数组不占用空间）来保存前缀积，使用一个临时变量来保存到目前为止的后缀积，最后再遍历answer数组的时候直接算出除当前元素外其余各元素的乘积，并更新后缀积。整体代码如下：

```java
// 方法二：方法一的空间优化
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // 先临时用answer当做前缀积
        answer[0] = nums[0];
        for(int i = 1; i < n; i++){
            answer[i] = answer[i - 1] * nums[i];
        }
        
        int rigthMulti = nums[n - 1]; // 用于保存后缀积的值
        answer[n - 1] = answer[n - 2]; // 更新最后一个位置的值
        for(int i = n - 2; i >= 1; i--){ // 更新中间位置的值
            answer[i] = answer[i - 1] * rigthMulti;
            rigthMulti = rigthMulti * nums[i]; // 更新后缀积
        }
        answer[0] = rigthMulti; // 更新第一个位置的值

        return answer;
    }
}
```

时间复杂度O(n)，空间复杂度由于只使用了answer数组，因此为O(1)。
