# 41. 缺失的第一个正数

[https://leetcode.cn/problems/first-missing-positive/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/first-missing-positive/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：哈希表

用一个哈希表记录原数组中出现过的值，然后从1开始逐个遍历正整数，直到找到第一个不在原数组中出现过的正整数，就是题目需要的返回值。完整代码如下：

```java
// 方法一：哈希表
class Solution {
    public int firstMissingPositive(int[] nums) {
        int len = nums.length;

        // 用HashSet记录出现过的数
        Set<Integer> hashSet = new HashSet<>();
        for(int i : nums){
            hashSet.add(i);
        }

        // 从正整数1开始遍历，找第一个没出现过的正整数
        for(int i = 1; i <= len; i++){
            if(!hashSet.contains(i)){
                return i;
            }
        }

        return len + 1;
    }
}
```

虽然此方法的时间复杂度为O(n)，但是空间复杂度为O(n)，不符合题意，可以考虑下面的方法二。

## 方法二（面试推荐）：将原数组视为哈希表

要找原数组中没有出现过的最小的正整数，那么这个最小正整数的值一定是大于等于1且小于等于len+1（len为数组长度）。既然最大值不会超过len+1，那么可以将原数组就视为哈希表，然后将原数组中的每个正整数都放到合适的位置去，具体做法是将原数组中的正整数n放到原数组中下标为n-1的位置去，比如正整数1就放到nums[0]。最后在从左到右开始遍历这个调整后的新数组，找到第一个某位置上的值不等于当前下标+1的那个位置，此时说明数组中没有原本在该位置上的那个正整数，此时直接返回该位置的下标+1，就是数组中没出现的最小正整数。

还可以这么理解，将数值大于等于1且小于等于len的树视为有家的人，这些人的家就在数组中下标为该人-1的位置。因此从头开始遍历每一个人，若该人有家，就将其送回家，否则直接跳过。最后再次遍历数组，找到第一个家里住着其他人的家，这个家原本住的那个人就是数组中未出现的最小整数。整体代码如下：

```java
// 方法二（面试推荐）：将原数组视为哈希表
class Solution {
    public int firstMissingPositive(int[] nums) {
        int len = nums.length;

        for(int i = 0; i < len; i++){
            // 如果这个人是有家的，那就看这个人是否在家，如果不在家就开始回家
            // 注意是用while而不是if，因为还需要判断交换后新指向的人是否有家
            while(nums[i] > 0 && nums[i] <= len && nums[nums[i] - 1] != nums[i]){
                swap(nums, i, nums[i] - 1);
            }
        }

        // 都已经回到自己家后，就从左到右开始找第一个家里面住着其他人的家
        for(int i = 0; i < len; i++){
            // 那个住着其他人的家里原本住的那个人就是数组中未出现的最小正整数
            if(nums[i] != i + 1){
                // 返回原住民
                return i + 1;
            }
        }

        // 如果每个家都有人，那么返回len + 1
        return len + 1;
    }

    // 交换人
    public void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

### 为什么是nums[i] != nums[nums[i] - 1]而不是而不是nums[i] != i+1？

- 原因一，因为整个while语句都是针对nums[i]这个人。前半段nums[i] > 0 && nums[i] <= len说的是nums[i]这个人有没有家，后半段nums[i] != nums[nums[i] - 1]判断的是nums[i]这个人现在在不在他的家里面，这里的逻辑是很顺畅的。而nums[i] != i+1这句代码表示的意思是i+1这个人现在在不在家，这跟nums[i]这个人根本没有任何关系。
