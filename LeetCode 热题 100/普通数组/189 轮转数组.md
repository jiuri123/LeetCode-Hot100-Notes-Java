# 189. 轮转数组

[https://leetcode.cn/problems/rotate-array/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/rotate-array/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：使用额外的数组

用一个新数组存放原数组中每个数在移动后的最终位置，最后再讲新数组复制到的原数组中。整体代码如下：

```java
// 方法一
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        int[] newArr = new int[n];
        for(int i = 0; i < n; i++){
            newArr[(i + k) % n] = nums[i];
        }
        System.arraycopy(newArr, 0, nums, 0 , n);
    }
}
```

时间复杂度：O(n)；

空间复杂度：O(n)，因为使用了额外数组。

## 方法二：三次翻转法

已知数组的后k（假设k已完成取余操作）个元素向后移动后，会被移动到数组中的前k个位置。由此可以先将数组的所有元素整体翻转，将后k个元素移动到数组的前面，然后在翻转前k个元素和后面的n-k个元素，这样就变相实现了元素的移动操作。当然也可以最后再做整体的翻转，下面的代码就是如此，实际效果是一样的。

```java
// 方法二（面试推荐）
// 时间复杂度：O(n)，每个元素被翻转两次，因此时间复杂度为O(2n) = O(n)；
// 空间复杂度：O(1)，只使用了常数个额外变量
class Solution {
    public void rotate(int[] nums, int k) {
        if (nums == null || nums.length <= 1) return;
        
        int n = nums.length;
        // 1. （易错点）处理 k 大于数组长度的情况
        // 因为k是有可能大于len的，所以要对len取余
        k %= n;
        if (k == 0) return;

        // 2. 三次翻转
        reverse(nums, 0, n - 1);      // 翻转整个数组
        reverse(nums, 0, k - 1);      // 翻转前 k 个
        reverse(nums, k, n - 1);      // 翻转剩余部分
    }

    // 辅助函数：翻转数组指定范围
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }
}
```

易错点：没有执行`k = k % len;`这段代码，但本题的k的大小是有可能超过数组的长度的，如果没有这行代码，会导致在reverse函数数组越界。
