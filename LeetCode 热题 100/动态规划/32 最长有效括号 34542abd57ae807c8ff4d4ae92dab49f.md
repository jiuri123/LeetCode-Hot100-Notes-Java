# 32. 最长有效括号

[https://leetcode.cn/problems/longest-valid-parentheses/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/longest-valid-parentheses/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：栈

```java
// 时间复杂度：O(n)，遍历一次字符串。
// 空间复杂度：O(n)，最坏情况下栈需要存储所有括号。
class Solution {
    public int longestValidParentheses(String s) {
        int maxLen = 0;
        // 栈用于存放括号的下标
        Deque<Integer> stack = new ArrayDeque<>();
        // 初始垫底一个 -1，用于计算从下标 0 开始的最长有效括号子串的长度
        // 如 s = "()()", s = "(())" 等情况……
        stack.push(-1);

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    // 如果栈空了，说明当前的 ')' 是多余的，将其下标入栈作为新的分割参照点
                    stack.push(i);
                } else {
                    // 当前长度 = 当前下标 - 此时栈顶记录的下标
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}

```

## 方法二：双向遍历

```java
// 时间复杂度：O(n)，虽然跑了两遍，但依然是线性的。
// 空间复杂度：O(1)，仅使用了常数个变量。这是此题的最优空间解法。
class Solution {
    public int longestValidParentheses(String s) {
        int left = 0, right = 0, maxLen = 0;
        
        // 正向遍历
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') left++;
            else right++;
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * right);
            } else if (right > left) {
                left = right = 0;
            }
        }
        
        // 记得重新初始化为 0
        left = right = 0;
        // 还需反向遍历，因为正向遍历可能会漏掉左括号大于右括号，导致最大值最后未更新的情况
        // 如 s = "(()" 等情况，如果只用正向遍历，会使得 maxLen 到最后都没法更新
        // 因为 left 一直大于 right，导致 if (left == right) 一直进不去
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') left++;
            else right++;
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);
            } else if (left > right) {
                left = right = 0;
            }
        }
        
        return maxLen;
    }
}
```
