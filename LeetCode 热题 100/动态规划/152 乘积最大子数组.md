# 152. 乘积最大子数组

[https://leetcode.cn/problems/maximum-product-subarray/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/maximum-product-subarray/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

```java
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) return 0;

        // 初始化为第一个元素
        int maxSoFar = nums[0]; // 记录以当前元素为结尾的乘积最大的子数组的乘积
        int minSoFar = nums[0]; // 记录以当前元素为结尾的乘积最小的子数组的乘积
        int result = nums[0]; // 记录乘积最大的结果

        for (int i = 1; i < nums.length; i++) {
            int curr = nums[i];

            // 关键点：如果当前是负数，乘以最大值会变最小，乘以最小值会变最大
            // 所以先交换最大值和最小值
            if (curr < 0) {
                int temp = maxSoFar;
                maxSoFar = minSoFar;
                minSoFar = temp;
            }

            // 计算以当前元素结尾的最大值和最小值
            // 要么是当前元素本身，要么是当前元素与之前的积相乘
            maxSoFar = Math.max(curr, maxSoFar * curr);
            minSoFar = Math.min(curr, minSoFar * curr);

            // 更新记录全局最大值
            result = Math.max(result, maxSoFar);
        }

        return result;
    }
}
```
