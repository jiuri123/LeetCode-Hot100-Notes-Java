# 230. 二叉搜索树中第 K 小的元素

[https://leetcode.cn/problems/kth-smallest-element-in-a-bst/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：递归法

```java
class Solution {
    int count = 0;
    int res = 0;
    public int kthSmallest(TreeNode root, int k) {
        findKthSmallest(root, k);
        return res;
    }

    public void findKthSmallest(TreeNode root, int k) {
        if(root == null){
            return;
        }

        findKthSmallest(root.left, k);
        count++;
        if(count == k){
            res = root.val;
            return;
        }else{
            findKthSmallest(root.right, k);
        }
    }
}
```

## 方法二：迭代法，面试推荐

```java
// 方法二：中序遍历迭代法
class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root;
        int count = 0;
        while(curr != null || !stack.isEmpty()){
            while(curr != null){
                stack.push(curr);
                curr = curr.left;
            }

            curr = stack.pop();
            count++;
            if(count == k) return curr.val;
            curr = curr.right;
        }
        return -1;
    }
}
```

## 方法三：Size 属性优化，面试进阶

这是大厂面试常问的**系统设计类**算法题：如果 BST 变动频繁（插入/删除），且查询 k 小的需求很多，该怎么办？
**核心思路**：在每个节点中维护一个 `size` 变量，存储**以该节点为根的子树中的节点总数**。
**查询逻辑（类似二分查找）**：
1. 计算左子树的节点个数 `leftSize`。
2. 如果 `k == leftSize + 1`：当前节点就是第 k 小。
3. 如果 `k <= leftSize`：第 k 小一定在**左子树**中，递归去左边找第 k 小。
4. 如果 `k > leftSize + 1`：第 k 小一定在**右子树**中，递归去右边找第 k - (leftSize + 1) 小。

```java
// 假设 TreeNode 结构已经包含了 size 属性
class MyTreeNode {
    int val;
    int size; // 关键：记录子树节点总数
    MyTreeNode left, right;
    
    MyTreeNode(int val) {
        this.val = val;
        this.size = 1;
    }
}

class OptimizedSolution {
    public int kthSmallest(MyTreeNode root, int k) {
        if (root == null) return -1;
        
        int leftSize = getCount(root.left);
        
        if (k == leftSize + 1) {
            return root.val;
        } else if (k <= leftSize) {
            return kthSmallest(root.left, k);
        } else {
            // 在右子树找，需要扣掉左子树和当前节点的个数
            return kthSmallest(root.right, k - leftSize - 1);
        }
    }

    private int getCount(MyTreeNode node) {
        return (node == null) ? 0 : node.size;
    }
}
```

**面试官可能会追问：**
• **问**：如何维持 `size` 的准确性？
• **答**：在执行 `insert` 或 `delete` 操作时，沿路经过的所有节点都进行 `size++` 或 `size--` 即可，这不会改变插入/删除操作的 O(H) 时间复杂度。
