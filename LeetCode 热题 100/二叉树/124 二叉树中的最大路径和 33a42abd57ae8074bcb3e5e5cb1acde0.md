# 124. 二叉树中的最大路径和

[https://app.notion.com](https://app.notion.com)

理解这道题的关键在于区分两个概念：

1. **以当前节点为“最高点”的最大路径和（左→中→右）**：即路径从左子树上来，经过当前节点，再下到右子树去（像一个倒 V 字型）。这个值用来更新全局最大值。
2. **当前节点能提供给父节点的最大单路径和（左→中或右→中）**：由于路径不能重复经过节点，当父节点调用子节点时，子节点只能选择左或右其中**一条**路径向上延伸。

```java
class Solution {
    // 全局最大路径和
    int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxSinglePathFrom(root);
        return maxSum;
    }

    /**
     * 返回从下往上以当前节点为终点的最大单路径和
     * 同时更新全局最大路径和
     */
    public int maxSinglePathFrom(TreeNode node) {
        if(node == null){
            return 0;
        }

        // 递归计算左右子树的最大单路径和（负值舍弃，即取 0）
        // 即计算的是从下往上以左/右子节点为终点的最大单路径和
        int leftMax = Math.max(0, maxSinglePathFrom(node.left));
        int rightMax = Math.max(0, maxSinglePathFrom(node.right));

        // 计算以当前节点为拐点的完整路径和（左 → 根 → 右）
        // 即将当前节点作为左右最大单路径的中间连接节点
        int pathThroughRoot = leftMax + node.val + rightMax;

        // 更新全局路径最大值
        maxSum = Math.max(maxSum, pathThroughRoot);

        // 返回从下往上以当前节点为终点的最大单路径和（供父节点连接）
        return node.val + Math.max(leftMax, rightMax);
    }
}
```
