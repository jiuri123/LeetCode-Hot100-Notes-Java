# 114. 二叉树展开为链表

[https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：寻找前驱结点（面试推荐）

对于当前节点，如果它有左子树，那么它的右子树在先序遍历中，一定会排在左子树的“最右下角节点”后面（因为根 → 左 → 右）。

算法步骤：

1. 从根节点开始遍历。
2. 如果当前节点的 **左子树不为空**：
    - 将当前节点的 **左子树** 移到右边。
    - 找到左子树中“最右边”的节点（即左子树先序遍历的最后一个节点）。
    - 将当前节点的 **右子树** 整体挂到这个“最右边节点”的右边。
    - 将当前节点的 **左子树置为空**。
3. 继续处理下一个右节点，直到遍历完成。

```java
// 方法一：寻找前驱结点（面试推荐）
class Solution {
    public void flatten(TreeNode root) {
        TreeNode curr = root;
        while(curr != null){ // 如果左子树不为空，需要进行搬运
            if(curr.left != null){ // 找到左子树的最右节点
                TreeNode pre = curr.left;
                while(pre.right != null) pre = pre.right;
                // 将原有的右子树接到左子树的最右节点的后面
                pre.right = curr.right;
                // 将左子树插到右边，并将左边置空
                curr.right = curr.left;
                curr.left = null;
            }
            // 继续处理下一个节点
            curr = curr.right;
        }
    }
}
```

## 方法二：倒序后序遍历

```java
// 方法二：倒序后序遍历（右 -> 左 -> 根）
class Solution {
    TreeNode pre = null;
    public void flatten(TreeNode root) {
        if(root == null) return;

        // 按照 右 -> 左 -> 根 的顺序遍历
        flatten(root.right);
        flatten(root.left);

        root.right = pre;
        root.left = null;
        pre = root;
    }
}
```
