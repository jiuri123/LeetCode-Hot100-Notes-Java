# 199. 二叉树的右视图

[https://leetcode.cn/problems/binary-tree-right-side-view/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/binary-tree-right-side-view/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一（面试推荐）

```java
// 方法一：层次遍历
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if(root == null) return res;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while(!queue.isEmpty()){
            int levelLen = queue.size(); // 当前层的节点个数

            for(int i = 0; i < levelLen; i++){
                TreeNode curr = queue.poll();

                // 如果是当前层的最后一个节点，加入结果集
                if(i == levelLen - 1) res.add(curr.val);

                if(curr.left != null) queue.offer(curr.left);
                if(curr.right != null) queue.offer(curr.right);
            } 
        }
        return res;
    }
}
```

## 方法二

```java
// 方法二：先序遍历，根 -> 右 -> 左
class Solution {
    List<Integer> res = new ArrayList<>();
    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        return res;
    }

    public void dfs(TreeNode root, int depth) {
        if(root == null) return;

        // 如果当前节点深度等于结果集的长度，说明这是该层第一个被访问的节点
        // 因为我们先递归右边，所以这就是最右侧节点
        if(depth == res.size()) res.add(root.val);
        
        // 注意：先递归右子树，再递归左子树
        dfs(root.right, depth + 1);
        dfs(root.left, depth + 1);
    }
}
```
