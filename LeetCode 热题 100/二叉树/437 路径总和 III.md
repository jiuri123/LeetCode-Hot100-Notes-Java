# 437. 路径总和 III

[https://leetcode.cn/problems/path-sum-iii/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/path-sum-iii/description/?envType=study-plan-v2&envId=top-100-liked)

**💡 核心思路：前缀和技巧**
这个问题的本质是在树的路径上寻找“连续子数组和等于 $K$”的变体。
1. **什么是前缀和？**
从根节点到当前节点的路径上，所有节点值之和。
2. **关键公式：**
如果路径上存在两个节点，从根到节点 A 的前缀和为 $S_1$，从根到节点 B（B 是 A 的子孙）的前缀和为 $S_2$，那么 **节点 A 到节点 B 之间的路径和 = $S_2 - S_1$**。
我们需要找的是：$S_2 - S_1 = targetSum$，即 **$S_1 = S_2 - targetSum$**。
3. **哈希表的作用：**
我们用一个 `Map<Long, Integer>` 来存储从根出发到当前路径上，各个“前缀和”出现的次数。
4. **回溯的重要性：**
当我们结束对某一棵子树的遍历，准备回到父节点去遍历另一棵子树时，必须将当前节点的前缀和从 Map 中减去。**这是为了防止左子树的路径和影响到右子树的计算。**

## 写法一

注意：由于节点值和 `targetSum` 可能较大，建议使用 `long` 类型处理和，防止溢出。

```java
// 方法一
class Solution {
    int res = 0;

    public int pathSum(TreeNode root, int targetSum) {
        // key: 前缀和, value: 该前缀和出现的次数
        Map<Long, Integer> preSumCountMap = new HashMap<>();

        // 初始化：前缀和为 0 出现 1 次
        preSumCountMap.put(0L, 1);

        // 开始 DFS 递归
        dfs(root, targetSum, 0L, preSumCountMap);

        return res;
    }

    public void dfs(TreeNode currNode, int targetSum, Long currNodePreSum, Map<Long, Integer> preSumCountMap) {
        if(currNode == null){
            return;
        }

        // 1. 更新当前路径的前缀和
        currNodePreSum += currNode.val;

        // 2. 在 Map 中寻找是否存在满足条件的前缀和 (currSum - targetSum)
        // 如果存在，说明从某个历史节点到当前节点的路径和刚好等于 targetSum
        res += preSumCountMap.getOrDefault(currNodePreSum - targetSum, 0);

        // 3. 将当前前缀和存入 Map，供子节点使用
        preSumCountMap.put(currNodePreSum, preSumCountMap.getOrDefault(currNodePreSum, 0) + 1);

        // 4. 递归遍历左右子树
        dfs(currNode.left, targetSum, currNodePreSum, preSumCountMap);
        dfs(currNode.right, targetSum, currNodePreSum, preSumCountMap);

        // 5. 【关键】回溯：在返回上一层之前，把当前前缀和次数减 1
        // 确保不会影响到非当前路径上的其他分支
        preSumCountMap.put(currNodePreSum, preSumCountMap.get(currNodePreSum) - 1);
    }
}
```

## 写法二

```java
// 方法二
class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        // key: 前缀和, value: 该前缀和出现的次数
        Map<Long, Integer> prefixSumCount = new HashMap<>();
        
        // 初始化：前缀和为 0 出现 1 次（处理路径恰好从根节点开始的情况）
        prefixSumCount.put(0L, 1);
        
        // 开始 DFS 递归
        return dfs(root, 0L, targetSum, prefixSumCount);
    }

    private int dfs(TreeNode node, long currSum, int targetSum, Map<Long, Integer> map) {
        if (node == null) {
            return 0;
        }

        // 1. 更新当前路径的前缀和
        currSum += node.val;

        // 2. 在 Map 中寻找是否存在满足条件的前缀和 (currSum - targetSum)
        // 如果存在，说明从某个历史节点到当前节点的路径和刚好等于 targetSum
        int res = map.getOrDefault(currSum - targetSum, 0);

        // 3. 将当前前缀和存入 Map，供子节点使用
        map.put(currSum, map.getOrDefault(currSum, 0) + 1);

        // 4. 递归遍历左右子树，累加结果
        res += dfs(node.left, currSum, targetSum, map);
        res += dfs(node.right, currSum, targetSum, map);

        // 5. 【关键】回溯：在返回上一层之前，把当前前缀和次数减 1
        // 确保不会影响到非当前路径上的其他分支
        map.put(currSum, map.get(currSum) - 1);

        return res;
    }
}
```
