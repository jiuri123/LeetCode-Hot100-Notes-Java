# 79. 单词搜索

[https://leetcode.cn/problems/word-search/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/word-search/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：DFS

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        int n = board.length;
        int m = board[0].length;
        char[] wordCharArray = word.toCharArray(); // 转换为数组提高访问效率

        // 遍历网格中的每一个格子作为起点
        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){
                // 只要找到一条路径，就立即返回 true
                if(dfs(board, i, j, wordCharArray, 0)){
                    return true;
                }
            }
        }
        return false;
    }

    public boolean dfs(char[][] board, int i, int j, char[] wordCharArray, int wordIndex) {
        // 边界条件判断：越界或当前字符不匹配
        if(i < 0 || j < 0 || i >= board.length || j >= board[0].length || board[i][j] != wordCharArray[wordIndex]){
            return false;
        }

        // 如果已经匹配到单词的最后一个字符，说明找到了
        if(wordIndex == wordCharArray.length - 1) return true;

        // --- 核心逻辑：回溯 ---
        // 1. 标记当前格子已访问（原地修改，避免重复使用）
        char temp = board[i][j];
        board[i][j] = '\0'; // 设置为一个网格中不会出现的特殊字符

        // 2. 向四个方向继续搜索
        boolean res = dfs(board, i + 1, j, wordCharArray, wordIndex + 1) ||
                        dfs(board, i, j + 1, wordCharArray, wordIndex + 1) || 
                        dfs(board, i - 1, j, wordCharArray, wordIndex + 1) || 
                        dfs(board, i, j - 1, wordCharArray, wordIndex + 1);
        
        // 3. 恢复现场（回溯）：无论是否找到，都要把字符改回来，不影响其他路径的尝试
        board[i][j] = temp;

        return res;
    }
}
```
