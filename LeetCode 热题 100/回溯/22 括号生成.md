# 22. 括号生成

[https://leetcode.cn/problems/generate-parentheses/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/generate-parentheses/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：回溯法（面试推荐）

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        backtrace(res, new StringBuilder(), 0, 0, n);
        return res;
    }

    public void backtrace(List<String> res, StringBuilder curr, int leftCount, int rightCount, int n) {
        // 终止条件：当前字符串长度达到了 2*n
        if(curr.length() == n * 2){
            res.add(curr.toString());
            return;
        }

        // 如果左括号还没放完，优先尝试放左括号
        if(leftCount < n){
            curr.append('(');
            leftCount++;
            backtrace(res, curr, leftCount, rightCount, n);
            curr.deleteCharAt(curr.length() - 1);
        }

        // 如果右括号数量少于左括号，可以放右括号
        if(rightCount < leftCount){
            curr.append(')');
            rightCount++;
            backtrace(res, curr, leftCount, rightCount, n);
            curr.deleteCharAt(curr.length() - 1);
        }
    }
}
```
