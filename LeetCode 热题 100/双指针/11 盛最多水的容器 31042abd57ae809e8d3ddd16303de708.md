# 11. 盛最多水的容器

[https://leetcode.cn/problems/container-with-most-water/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/container-with-most-water/description/?envType=study-plan-v2&envId=top-100-liked)

思路是使用双指针法，设置两个指针分别指向数组的左右两端，表示当前容器的宽，然后计算当前容器可以容纳的水量。与最大值比较并保存之后，就开始移动这两个指针，这一步是本题的关键。具体做法是每次将两个指针中高度较小的那一个指针往内移动一格，然后继续计算新容器的容量，之后就是重复本操作，直到左右两个指针相遇。

为什么每次移动指针的时候要先移动高度较小的那个指针呢？因为只有移动较小的那个指针，才**有可能**使得后续计算得到的容器容量超过当前的容器容量。注意是有可能，不是一定。因为移动较小的指针，虽然使得宽变短了（减小了1），但是后续遇到的指针的高度是有可能超过当前两个指针中高度最小的那个指针的，这样才有可能使得蓄水高度增加。反之，如果每次移动指针的时候要先移动高度较大的那个指针，那么后续遇到的最好情况也就是保持蓄水量不变，不可能再使得容器的蓄水量增加了，因为当前两个指针中高度较小的那个指针就限制了将来蓄水量的最大值，因此每次移动指针的时候先移动高度较大的那个指针是没有意义的，这样做不会让我找到比现在的蓄水量更大的容器。综上，每次移动指针的时候要先移动高度较小的那个指针才有可能使得我找到蓄水量比现在的容器更大的那个容器，其他都是徒劳。

还有一个特殊情况，就是两个指针的高度相等怎么办？此时既可以只移动任意一个指针，也可以同时移动两个指针，但是同时移动两个指针更加省时间。为什么时移动两个指针更加省时间呢？因为如果只移动一个指针（不管哪一个），那么不管后续怎样移动怎样计算，后续容器的容量都不可能超过当前计算的容器容量了，而唯一有可能超过当前计算的容器容量的情况（没有移动指针前的情况），就是同时移动两个指针（富贵险中求，中间有可能出现两个指针的高度都远远大于当前两个指针的高度的情况）。

整体代码如下：

```java
class Solution {
    public int maxArea(int[] height) {
        // 初始化左指针在数组最左端，右指针在数组最右端
        int left = 0;
        int right = height.length - 1;
        
        // 用于记录遍历过程中的最大面积
        int resArea = -1;

        // 当左指针小于右指针时，继续循环
        while (left < right) {
            // 容器的高度由较短的那根木板决定（木桶效应）
            int minHeight = Math.min(height[left], height[right]);
            
            // 计算当前左右指针指向的木板所构成的容器面积
            // 面积 = 底（右索引 - 左索引） * 高（左右两板中的较短者）
            int tempArea = minHeight * (right - left);
            
            // 更新全局最大面积
            resArea = Math.max(resArea, tempArea);

            // 核心逻辑：移动指针
            // 为什么要移动较短的那根？
            // 因为容器的宽度在减小，只有通过寻找更长的板子才有可能获得更大的面积。
            // 如果移动较长的板子，容器高度依然受限于较短的那根，且宽度变窄，面积只会减小。
            
            if (height[left] < height[right]) {
                // 左侧较短，尝试向右移动左指针寻找更高板子
                left++;
            } else if (height[left] > height[right]) {
                // 右侧较短，尝试向左移动右指针
                right--;
            } else {
                // 两者相等时，移动任意一个或同时移动，都不会错过最优解
                left++;
                right--;
            }
        }
        
        // 返回找到的最大面积
        return resArea;
    }
}
```
