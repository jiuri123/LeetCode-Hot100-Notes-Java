# 155. 最小栈

[https://leetcode.cn/problems/min-stack/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/min-stack/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

```java
class MinStack {
    // 主栈：存储所有入栈的元素
    Deque<Integer> stack;
    // 辅助栈（最小栈）：存储当前状态下的最小值
    // 栈顶元素始终是当前所有元素中的最小值
    Deque<Integer> minStack;

    /** 构造函数：初始化主栈和辅助栈 */
    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }
    
    /**
     * 入栈操作
     * 1. 元素压入主栈
     * 2. 如果辅助栈为空，或当前元素小于等于辅助栈栈顶，则同时压入辅助栈
     * 这样保证辅助栈栈顶始终是当前最小值
     */
    public void push(int val) {
        stack.push(val);
        // 注意：这里用 <= 而不是 <，是为了处理重复最小值的情况
        // 例如：连续压入两个 5，最小栈也要有两个 5，这样 pop 时才正确
        if(minStack.isEmpty() || val <= minStack.peek()){
            minStack.push(val);
        }
    }
    
    /**
     * 出栈操作
     * 1. 主栈栈顶元素出栈
     * 2. 如果出栈的元素等于辅助栈栈顶（即当前最小值），辅助栈也出栈
     */
    public void pop() {
        int popNum = stack.pop();
        // 如果弹出的是当前最小值，辅助栈也要同步弹出，保持最小值正确性
        if(popNum == minStack.peek()){
            minStack.pop();
        }
    }
    
    /** 获取主栈栈顶元素 */
    public int top() {
        return stack.peek();
    }
    
    /** 获取当前栈中的最小值，时间复杂度 O(1) */
    public int getMin() {
        return minStack.peek();
    }
}
```
