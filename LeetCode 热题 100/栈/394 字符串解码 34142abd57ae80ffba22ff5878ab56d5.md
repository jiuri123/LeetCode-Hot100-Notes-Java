# 394. 字符串解码

[https://leetcode.cn/problems/decode-string/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/decode-string/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

```java
class Solution {
    public String decodeString(String s) {
		    // 两个栈用于保存现场
        Deque<Integer> kStack = new ArrayDeque<>();
        Deque<StringBuilder> lastResStack = new ArrayDeque<>();

        StringBuilder curRes = new StringBuilder(); // 递归函数的局部变量
        int k = 0; // 堆叠次数
        for(char c : s.toCharArray()){
            if(Character.isDigit(c)){ // 如果是数字
                // 处理多位数的情况，例如 "100[a]"
                k = k * 10 + c - '0';
            }else if(c == '['){ // 如果是左括号，说明递归调用一个新函数
                // 则保存当前旧函数的现场，并重置状态
                kStack.push(k); // 记录新函数的堆叠次数
                lastResStack.push(curRes); // 记录旧函数现场
                // 重置现场
                k = 0;
                curRes = new StringBuilder();
            }else if(c == ']'){ // 如果是右括号，说明新函数结束递归，准备返回
                // 因此需要获得新函数的返回结果，并恢复上一层旧函数的现场
                int curResK = kStack.pop(); // 获得当前括号内字符串的重复值
                StringBuilder temp = new StringBuilder(); // 保存新函数的返回结果
                while(curResK-- != 0){ // 计算新函数的返回结果
                    temp.append(curRes); 
                }
                curRes = lastResStack.pop().append(temp); // 递归结束，恢复现场
            }else{ 
                curRes.append(c); // 如果是字母，则缓慢添加
            }
        }
        // 递归结束后，curRes保存的就是最终的结果
        return curRes.toString();
    }
}
```
