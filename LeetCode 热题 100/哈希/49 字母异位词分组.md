# 49. 字母异位词分组

[https://leetcode.cn/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：暴力解法，超时

第一种方法是我自己的方法，就是每遇到一个单词，就是去遍历该单词后面的那些单词，把当前单词的所有字母异位词都找出来，并用一个数组标记那些单词是已经被使用过了的。整体代码如下：

```java
// 方法一：暴力解法，超时
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> res = new ArrayList<>();
        boolean[] isSelect = new boolean[strs.length];
        for(int i = 0; i < strs.length; i++){
            if(isSelect[i] == false){
                isSelect[i] = true;
                List<String> innerList = new ArrayList<>();
                innerList.add(strs[i]);
                for(int j = i + 1; j < strs.length; j++){
                    if(isSelect[j] == false && isAnagram(strs[i], strs[j]) == true){
                        isSelect[j] = true;
                        innerList.add(strs[j]);
                    }
                }
                res.add(innerList);
            }
        }
        return res;
    }

    // 判断两只字符串是否是字母异位词
    public boolean isAnagram(String str1, String str2){
        int[] myMap = new int[26];
        for(int i = 0; i < str1.length(); i++){
            myMap[str1.charAt(i) - 'a']++;
        }

        for(int i = 0; i < str2.length(); i++){
            myMap[str2.charAt(i) - 'a']--;
        }

        for(int i = 0; i < 26; i++){
            if(myMap[i] != 0){
                return false;
            }
        }

        return true;
    }
}
```

这里判断两只字符串是否是字母异位词使用的方法是：[**242.有效的字母异位词**](https://app.notion.com/p/242-1a542abd57ae80fa9c34e2c0409c0cf8?pvs=21) ，但是这种方法超时了。

## 方法二：排序法（面试推荐）

思路是使用一个哈希表来收集不同的字母异位词，问题在于该用什么东西来作为同一类字母异位词的哈希表的键呢？可以发现字母异位词只是字母调换了位置，如果将字母异位词进行排序，那么得到的字符串肯定都是相同，因此可以排序后的字符串作为哈希表的键，通过这个键来收集同一类字母异位词。代码如下：

```java
// 方法二：排序法（面试推荐）
// 将排序后的字符串作为哈希表的键
// 时间复杂度：O(nklogk)，其中n是单词个数，k是单词最大长度。
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for(String str : strs){
            char[] charArray = str.toCharArray();
            // 对每个字符串都进行排序，并将排序后的字符串作为哈希表的键
            Arrays.sort(charArray);
            String key = new String(charArray);
            List<String> AnagramList = map.getOrDefault(key, new ArrayList<>());
            AnagramList.add(str);
            map.put(key, AnagramList);
        }
        return new ArrayList<>(map.values());
    }
}
```

知识点：

1. 将`String`转换成`char[]`：使用`toCharArray()`函数；
2. 将`char[]`转换成`String`：直接使用`new String(charArray)`；
3. `map.values()`的返回类型：`Collection<List<String>>`，而`new ArrayList<>(map.values());`的意思是创建一个新的 `ArrayList`，然后把 `map.values()`里的每个元素放进去。

## 方法三：计数法（加分项）

从方法二可以知道，用哈希表来解决此类寻找并收集的问题非常可行，而关键就在于如何找到同类的字母异位词的相同点，并将其作为哈希表的键值。方法二使用的是排序后的字符串作为键值，因为需要排序，因此时间复杂度还是有点高。可以想想还有什么东西是可以作为键值来收集同类字母异位词，同时又可以避免排序的。可以这样，将字符串中每个出现次数大于0的字母及其出现次数按顺序进行拼接，形成一个新的字符串，将这个字符创作为哈希表的键。为什么这样可行？因为同一类字母异位词中每个字母的出现次数一定是相同的，那么通过上述方法得到的键值一定可以唯一表示同一类字母异位词，因此是可行的。代码如下：

```java
// 方法三：计数法（加分项）
// 将每个出现次数大于 0 的字母和出现次数按顺序拼接成字符串，作为哈希表的键
// 时间复杂度：O(nk)，其中k是单词最大长度，将排序的klogk降低到k
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for(String str : strs){
            int[] counts = new int[26];
            int length = str.length();
            // 对每个字符串中出现的字母进行计数
            for(int i = 0; i < length; i++){
                counts[str.charAt(i) - 'a']++;
            }

            // 将每个出现次数大于 0 的字母和出现次数拼接成字符串，作为哈希表的键
            StringBuffer sb = new StringBuffer();
            for(int i = 0; i < 26; i++){
                if(counts[i] != 0){
                    sb.append((char)(i + 'a'));
                    sb.append((counts[i]));
                }
            }
            String key = sb.toString();
            List<String> list = map.getOrDefault(key, new ArrayList<>());
            list.add(str);
            map.put(key, list);
        }
        return new ArrayList<>(map.values());
    }
}
```

## 总结

方法二和方法三的共同思路都是考虑用一个哈希表来组合字母异位词，然后去找出字母异位词的共同点来作为哈希表的键，这样不仅可以更加快速的找到字母异位词，还能将相同的字母异位词存储在一起。因此以后遇到类似的查找题目，就可以考虑用哈希表，而用哈希表最关键的地方就在于如何找出某一集合的共同点，并将该共同点作为哈希表的键。

比如方法二找出的字母异位词的共同点就是排序后的字母异位词一定是相同的；而方法二找出的字母异位词的共同点就是将每个出现次数大于 0 的字母和出现次数按顺序进行拼接而成的字符串是相同的。最后用这个相同点作为哈希表的键来收集其他的字母异位词。
