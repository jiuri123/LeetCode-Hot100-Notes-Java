# 128. 最长连续序列

[https://leetcode.cn/problems/longest-consecutive-sequence/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/longest-consecutive-sequence/description/?envType=study-plan-v2&envId=top-100-liked)

思路就是首先将数组中的数字全部存储到一个set中，这样做有两个目的：一是去重；二是将后续查找数字操作的时间复杂度降低到O(1)。接着遍历set中的数字，对于每一个数字，看看这个数字是不是某个连续序列的开头元素，如果不是开头的元素，说明以这个元素作为开头的那个连续序列的长度肯定不是最长的，因为这个序列的前面还可以继续补充元素，使得序列的长度更长，此时直接跳过该元素就好了。如何判断这个元素就是某个序列的开头元素呢？那就以这个元素为头元素，不断的去set中找这个元素+1、这个元素+2……的值，直接找不到为止，此时就可以算出以这个元素为开头的序列的长度是多少，最后进行比较记录就可以了。

那么具体怎么判断当前遍历到的元素是否是某个连续序列的开头元素呢？其实也很简单，就是直接去看看set中是否存在这个元素-1的值，如果存在就说明当前元素不能作为起点，因为肯定还存在一个元素，使得从这个元素开头的连续序列长度可以更长。

代码如下：

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        // 使用set去重，并降低元素查找的时间复杂度
        Set<Integer> st = new HashSet<>();
        for(int num : nums){
            st.add(num);
        }

        // 记录连续最长序列的长度
        int maxLen = 0;
        for(int n : st){ // 易错点：for循环不是遍历原数组(int n : nums)，而是遍历Set
            // 如果数字不是开头，说明还有更长的序列，那么直接跳过该元素
            if(st.contains(n - 1)){
                continue;
            }else{ // 如果找到了某个序列开头的那个元素
		            // 就计算这个序列的长度
                int tempLen = 1;
                int m = n + 1;
                // 计算以该元素开头的连续序列的长度
                while(st.contains(m)){
                    tempLen++;
                    m++;
                }

                // 更新连续最长序列的长度
                maxLen = Math.max(maxLen, tempLen);
            }
        }

        return maxLen;
    }
}
```

易错点：for循环不是遍历原数组（int n : nums），而是遍历Set，不然会超时！

- 因为set是经过去重的，元素相对来说没那么多；而原数组没有经过去重，有可能会超时
