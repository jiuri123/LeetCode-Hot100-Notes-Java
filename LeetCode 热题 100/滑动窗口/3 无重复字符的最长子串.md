# 3. 无重复字符的最长子串

[https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

本题需要找到一个字符串当中不含重复字符的最长子串的长度，注意这里的子串是需要连续的。可以使用滑动窗口法，即设置两个指针，分别表示当前遍历到的临时字符串的左右边界。起始的时候左右指针都在0的位置，然后移动右指针，同时判断当前遍历到的字符是否在当前左右指针所包含的这个临时字符串中是否出现过。如果出现过，那么这个字符就不能直接加入到临时字符串当中，此时应该不断地移动左指针，直到当前这个临时字符串中不含有当前所遇到的这个字符，这时候再将所遇到的这个字符加入到临时字符串当中。如果没出现过的话，那就直接加入到临时字符串中，然后记录此临时字符串的长度，并将其与之前记录的最长长度进行比较。循环往复，直到右边界超出原字符串的最长长度，最后返回中间记录的最长长度即可。代码如下：

```java
// 方法一：使用StringBuilder存储临时字符串
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 记录临时字符串的最大长度
        int maxLength = 0;
        // 记录已在临时字符串中出现的字符
        Set<Character> charOccur = new HashSet<>();
        // 存储临时字符串
        StringBuilder sb = new StringBuilder();
        char[] charArray = s.toCharArray();
        for(int i = 0; i < charArray.length; i++){
            char ch = charArray[i];
            // 临时字符串中已包含此字符
            while(charOccur.contains(ch)){
                // 不断移动左边界
                charOccur.remove(sb.charAt(0));
                sb.deleteCharAt(0);
            }
            // 直到临时字符串中无此字符
            // 就将此字符加入到临时字符串中
            charOccur.add(ch);
            sb.append(ch);
            if(sb.length() > maxLength){
                maxLength = sb.length();
            }
        }
        return maxLength;
    }
}
```

## 方法二（面试推荐）

```java
// 方法二（面试推荐）：方法一的升级，直接使用一个左指针记录字符串的左边界
class Solution {
    public int lengthOfLongestSubstring(String s) {
        if(s == null || s.length() == 0){
            return 0;
        }
        char[] charArray = s.toCharArray();
        Set<Character> window = new HashSet<>();
        int left = 0;
        int right = 0;
        int maxLen = 0;
        while(right < s.length()){
            if(!window.contains(charArray[right])){ // 如果不包含，则直接加入
                window.add(charArray[right]);
                right++;
                maxLen = Math.max(maxLen, right - left);
            }else{ // 否则缩小窗口，直到不包含
                while(window.contains(charArray[right])){
                    window.remove(charArray[left]);
                    left++;
                }
            }
        }
        
        return maxLen;
    }
}

// 简洁版
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> window = new HashSet<>();
        int n = s.length();
        int left = 0;
        int right = 0;
        int maxSubStringLen = 0;

        while(right < n){
            // 拿到当前右指针指向的新字符
            char newChar = s.charAt(right);
            
            // 先消除窗口中的重复字符
            while(window.contains(newChar)){
                window.remove(s.charAt(left));
                left++;
            }

            // 再将新字符加入窗口
            window.add(newChar);
            right++;
            maxSubStringLen = Math.max(maxSubStringLen, right - left);
        }
        return maxSubStringLen;
    }
}
```
