# 438. 找到字符串中所有字母异位词

[https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一（面试推荐）

方法一其实刚开始就想到了，但是觉得复杂度太高，而且想着应该不会这么简单，因此就直接放弃了，但是事实这就是常规解法。思路就是在主串中设置一个和子串长度相同的滑动窗口，然后设置两个数组分别统计滑动窗口和子串中各个字母的数量，最后比较这两个数组就可以得出是否是字母异位词。代码如下：

```java
// 方法一（面试推荐）：滑动窗口 + 频率数组
// 时间复杂度：时间复杂度为O(n)
// 空间复杂度：O(1)（因为数组大小固定为 26）
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int sLen = s.length();
        int pLen = p.length();
        
        // 如果 p 比 s 还要长，不可能存在异位词
        if(sLen < pLen){
            return new ArrayList<>();
        }

        List<Integer> ans = new ArrayList<>();
        int[] sCount = new int[26];
        int[] pCount = new int[26];

        // 初始化计数器：统计 p 的字符频率和 s 第一个窗口的频率
        for(int i = 0; i < pLen; i++){
            sCount[s.charAt(i) - 'a']++;
            pCount[p.charAt(i) - 'a']++;
        }

        // 检查第一个窗口是否匹配
        // 本题关键：使用Arrays.equals()来比较两个数组是否相同
        if(Arrays.equals(sCount, pCount)){
            ans.add(0);
        }

				// 开始滑动窗口
        for(int i = pLen; i < sLen; i++){
		        // 右边界进一个
            sCount[s.charAt(i) - 'a']++;
            // 左边界删一个
            sCount[s.charAt(i - pLen) - 'a']--;
            
            // 比较当前新的窗口和 p 的频率是否一致
            // Arrays.equals 比较固定长度为 26 的数组，时间复杂度是 O(1)
            if(Arrays.equals(sCount, pCount)){
                ans.add(i - pLen + 1);
            }
        }

        return ans;
    }
}
```

Arrays.equals为什么在这题时间复杂度是O(1)？

- 从严格定义上讲，`Arrays.equals` 的复杂度取决于数组长度。但由于本题的字符集大小固定为 26（小写英文字母），数组长度是一个**常数**。因此，相对于输入字符串长度 n 而言，每次比较的操作耗时是恒定的，即 O(1)。所以整个算法的总时间复杂度维持在 O(n)。

## 方法二

方法二是方法一的优化。其实可以不用设置两个数组来记录滑动窗口和p中各个字母的数量，然后通过这两个数组来判断是否是异位词。完全还可以有另一种方法，就是设置一个differ变量，这个差值变量记录的是：**滑动窗口与子串p中数量不同的字母的个数**。然后通过differ来判断滑动窗口与p是否是异位词：如果differ=0，说明滑动窗口与p没有数量不同的字母，那么此时就是异位词；如果differ!=0，说明滑动窗口与p还存在数量不同的字母，此时就不是异位词。

问题的关键其实在于怎么更新differ的值。可以设置一个count数组，其中的值表示的意思是滑动窗口中各个字母的数量 - p中各个字母的数量。然后在移动滑动窗口的左边界的时候，此时通过判断旧窗口左边界的元素在count数组中的值来更新differ的值，假如旧窗口左边界的元素在count数组中的值为1，也就说明这个元素在窗口中的数量比这个元素在p中的数量要多1，而将该元素移除出滑动窗口之后，这个元素在窗口中的数量和这个元素在p中的数量就相同了，那么此时说明滑动窗口与p中数量不同的字母个数就要减少1个，此时也就是更新differ的时机。后续还有三种情况是更新differ的时机，也是同理。因此可以总结出更新differ的时机在于移动滑动窗口左右边界的时候。

详细过程见下面代码：

```java
// 方法二：滑动窗口（优化版，使用差值记录不同）
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int sLen = s.length();
        int pLen = p.length();
        if(sLen < pLen){
            return new ArrayList<>();
        }

        List<Integer> res = new ArrayList<>();
        int[] count = new int[26];
        for(int i = 0; i < pLen; i++){
            // 相当于是计算：s的滑动窗口中各个字母的数量 - p中各个字母的数量
            count[s.charAt(i) - 'a']++;
            count[p.charAt(i) - 'a']--;
        }

        // 记录当前滑动窗口与字符串p中数量不同的字母的个数
        int differ = 0;
        for(int i = 0; i < 26; i++){
            if(count[i] != 0){
                differ++;
            }
        }

        // 判断起始窗口是否是p的异位词
        if(differ == 0){
            // 如果没有数量不相同的元素，就是异位词
            res.add(0);
        }

        for(int i = pLen; i < sLen; i++){
            // 开始移除滑动窗口中最左边的那个元素，同时判断是否是更新differ的时机
            if(count[s.charAt(i - pLen) - 'a'] == 1){ // 旧窗口中最左边的那个元素的数量与字符串p中的数量从不同变得相同（本来滑动窗口中这个元素的数量比p中这个元素的数量多1，现在如果将这个元素移除出去，那么数量就相同了，下面同理）
                differ--;
            }else if(count[s.charAt(i - pLen) - 'a'] == 0){ // 旧窗口中最左边的那个元素的数量与字符串p中的数量从相同变得不同
                differ++;
            }
            count[s.charAt(i - pLen) - 'a']--;

            // 开始增加滑动窗口中最右边的那个元素的下一个元素，同时判断是否是更新differ的时机
            if(count[s.charAt(i) - 'a'] == -1){ // 旧窗口中即将加入窗口的那个元素的数量与字符串p中的数量从不同变得相同
                differ--;
            }else if(count[s.charAt(i) - 'a'] == 0){ // 旧窗口中即将加入窗口的那个元素的数量与字符串p中的数量从相同变得不同
                differ++;
            }
            count[s.charAt(i) - 'a']++;

            // 判断新的窗口是否是p的异位词
            if(differ == 0){
                res.add(i - pLen + 1);
            }
        }
        return res;
    }
}
```
