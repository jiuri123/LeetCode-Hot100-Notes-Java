# 2. 两数相加

[https://leetcode.cn/problems/add-two-numbers/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/add-two-numbers/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

方法一是自己的方法，虽然空间复杂度很低，但是过程较复杂，很多细节，面试时使用容易出错，因此不建议用。思路是遍历两个链表，然后相加对应的结点值和进位值，然后记录进位值和更新当前结点相加后的值，重复上述循环，直到短链表到达结尾。然后就开始特殊处理长链表的后续剩余节点。此时要考虑到这些后续结点都是9的特殊情况。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */

// 方法一：自己的方法，直接在原链表上进行，空间复杂度为O(1)
// 时间复杂度为O(m+n)，m和n分别为两链表的长度
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // 计算链表1的长度
        ListNode l1Node = l1;
        int l1Len = 0;
        while(l1Node != null){
            l1Len++;
            l1Node = l1Node.next;
        }

        // 计算链表2的长度
        ListNode l2Node = l2;
        int l2Len = 0;
        while(l2Node != null){
            l2Len++;
            l2Node = l2Node.next;
        }

        // 设定长链表和短链表的虚拟头结点
        ListNode longListFakeHead = new ListNode();
        ListNode shortListFakeHead = new ListNode();
        if(l1Len >= l2Len){
            longListFakeHead.next = l1;
            shortListFakeHead.next = l2;
        }else{
            longListFakeHead.next = l2;
            shortListFakeHead.next = l1;
        }

        // 开始相加
        int carry = 0;
        ListNode longListNode = longListFakeHead;
        ListNode shortListNode = shortListFakeHead;
        while(shortListNode.next != null){
            int sum = shortListNode.next.val + longListNode.next.val + carry;
            longListNode.next.val = sum % 10;
            carry = sum / 10;
            shortListNode = shortListNode.next;
            longListNode = longListNode.next;
        }

        // 短链表到头的时候，长链表不一定到头
        // 用while是为了防止长链表后面的节点值都是9的情况
        while(longListNode.next != null && carry != 0){
            int sum = longListNode.next.val + carry;
            longListNode.next.val = sum % 10;
            carry = sum / 10;
            longListNode = longListNode.next;
        }

        // 最后的进位需要新建一个节点
        if(longListNode.next == null && carry == 1){
            ListNode newNode = new ListNode(1, null);
            longListNode.next = newNode;
        }

        return longListFakeHead.next;
    }
}
```

## 方法二（面试推荐）

新建一个链表用来存储求和的结果，然后依次计算每个节点的求和值，新建节点并使用尾插法插入到新链表中。最后记得单独处理最后一个节点的进位值。

```java
// 方法二(推荐)：新建一个单链表来存储计算结果
// 时间复杂度为O(m+n)，m和n为两链表的长度
// 空间复杂度为O(m+n)，m和n为两链表的长度
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // 新建一个链表，用来存储求和结果
        ListNode pre = new ListNode(-1, null);
        ListNode cur = pre;

        int carry = 0;
        while(l1 != null || l2 != null){
            // 相当于是给位数小的那个数的高位补0
            int x = (l1 == null ? 0 : l1.val);
            int y = (l2 == null ? 0 : l2.val);
            int sum = x + y + carry;
            cur.next = new ListNode(sum % 10, null);
            carry = sum / 10;
            cur = cur.next;

            // 易错点：不要直接移动指针
            if(l1 != null) l1 = l1.next;
            if(l2 != null) l2 = l2.next;
        }

        // 单独处理最后一个节点的进位
        if(carry == 1){
            cur.next = new ListNode(1);
        }

        return pre.next;
    }
}
```

此方法虽然时间复杂度高，但是过程简单易懂，逻辑清晰，不易出错，面试推荐。
