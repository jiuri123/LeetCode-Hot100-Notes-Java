# 141. 环形链表

[https://leetcode.cn/problems/linked-list-cycle/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/linked-list-cycle/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：哈希表

从头开始遍历元素，然后用一个哈希表记录遍历过的元素。如果遍历的过程中遇到了之前遍历过的元素，说明刚刚从环里面出来，那么也就说明是有环的。

```java
// 方法一：哈希表
public class Solution {
    public boolean hasCycle(ListNode head) {
        Set<ListNode> meeted = new HashSet<>();
        ListNode temp = head;
        while(temp != null){
            if(!meeted.add(temp)){
                return true;
            }
            temp = temp.next;
        }
        return false;
    }
}
```

## 方法二：快慢指针

设置一个快指针和一个慢指针，快指针每次走两步，慢指针每次走一步。如果有环的话，那么快指针和慢指针最终一定会在环中相遇。为什么有环就一定会相遇？因为快指针每次比慢指针多走一步，这也就意味着在环中的时候快慢指针之间的距离每次都会减1，说明快指针和慢指针最终都会停留在一个节点，即相遇。

```java
// 方法二：快慢指针
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while(fast != null && fast.next != null){
            slow = slow.next;
            fast = fast.next.next;
            if(slow == fast){
                return true;
            }
        }

        return false;
    }
}
```
