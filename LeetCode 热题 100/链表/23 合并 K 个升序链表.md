# 23. 合并 K 个升序链表

[https://leetcode.cn/problems/merge-k-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/merge-k-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：优先队列（面试推荐）

创建一个最小堆（优先队列），将最小堆设置成按照结点的值从小到大进行排列。然后将数组中每个链表的头结点（也就是值最小结点）加入到最小堆当中。接着从最小堆中不停地弹出当前最小的结点，通过尾插法加入到新的链表当中，同时判断该最小结点是否还有下一个结点（即该链表的结点是否都已经加入过堆当中了），如果有的话继续加入到堆中。

想象有n个队伍，每个队伍的队头元素就是该队的代表，然后队伍与队伍之间按照每队代表的大小进行排列，然后每次取这些代表中值最小的加入到一个新的队伍当中。由于这个队伍的代表被选走了，那么就将这个队伍队头元素的下一个元素作为这个队伍的新代表，然后重新按照每队代表的大小进行排列。最后所有队伍的每个元素都合并在了一个新的队伍当中。

```java
// 方法一：优先队列（面试推荐）
// 时间复杂度：O(NlogK)，其中N是总节点数。每次从堆中插入/弹出的复杂度是O(log K)，总共操作N次。
// 空间复杂度：O(K)。堆中最多只维持K个元素（每个链表派出一个代表）。
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // 1. 边界处理：如果数组为空或长度为0，直接返回null
        if (lists == null || lists.length == 0) {
            return null;
        }

        // 2. 创建一个最小堆 (Priority Queue)
        // 比较规则：节点值 val 越小的优先级越高
        // 面试技巧：Lambda 表达式写法简洁，Java 8+ 常用
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);

        // 3. 初始化：将每个非空链表的头节点放入堆中
        for (ListNode node : lists) {
            if (node != null) {
                pq.offer(node);
            }
        }

        // 4. 创建哑节点 (Dummy Head) 作为结果链表的起点
        // 使用 dummy 节点可以避免处理头节点为空的繁琐逻辑
        ListNode dummy = new ListNode(-1);
        ListNode tail = dummy;

        // 5. 循环从堆中取出最小元素，直到堆为空
        while (!pq.isEmpty()) {
            // 取出当前最小的节点
            ListNode minNode = pq.poll();
            
            // 将其接到结果链表的末尾
            tail.next = minNode;
            tail = tail.next;

            // 关键：如果该节点还有后续节点，将后续节点放入堆中继续参与排序
            if (minNode.next != null) {
                pq.offer(minNode.next);
            }
        }

        // 6. 返回哑节点的下一个节点，即真正的合并后头节点
        return dummy.next;
    }
}
```

## 方法二：迭代归并排序（加分项）

将数组中的链表看成是归并排序中已经经过划分的子链表，然后按照归并排序的合并逻辑，将数组内的子链表两两合并，向上合并完成之后，数组中第一个位置就是合并后链表的头结点。

```java
// 方法二：迭代法归并排序
// 时间复杂度：O(nlogk)
// 空间复杂度：O(1)
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // 易错点一：未处理边界情况
        if (lists == null || lists.length == 0) {
            return null;
        }

        // 开始合并操作
        for(int step = 1; step < lists.length; step <<= 1){
            for(int i = 0; i < lists.length; i += (step << 1)){
                if(i + step >= lists.length){ 
                    break;
                }else{
                    // 每次将合并后的链表放到原左子链表的位置
                    lists[i] = Merge(lists[i], lists[i + step]);
                }
            }
        }

        // 第一个位置就是合并后的链表的头结点
        return lists[0];
    }

    // 合并排序两个子链表
    public ListNode Merge(ListNode left, ListNode right) {
        ListNode fakeHead = new ListNode(-1, null);
        ListNode newTail = fakeHead;

        while(left != null && right != null){
            if(left.val <= right.val){
                newTail.next = left;
                left = left.next;
            }else{
                newTail.next = right;
                right = right.next;
            }
            newTail = newTail.next;
        }

        // 易错点二：易写成newTail = (left == null ? right : left);了
        newTail.next = (left == null ? right : left);

        return fakeHead.next;
    }
}
```
