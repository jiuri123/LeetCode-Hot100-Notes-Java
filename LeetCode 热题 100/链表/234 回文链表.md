# 234. 回文链表

[https://leetcode.cn/problems/palindrome-linked-list/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/palindrome-linked-list/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：额外数组+双指针

将原来链表中的元素加入到一个新的数组当中，然后通过双指针的方法对数组进行回文判断。

```java
// 方法一：额外数组+双指针
// 时间复杂度：O(n)
// 空间复杂度：O(n)
class Solution {
    public boolean isPalindrome(ListNode head) {
        // 将链表中的元素加入到数组中
        List<Integer> vals = new ArrayList<>();
        ListNode node = head;
        while(node != null){
            vals.add(node.val);
            node = node.next;
        }

        // 使用双指针法判断回文
        int left = 0;
        int right = vals.size() - 1;
        while(left < right){
            if(vals.get(left).equals(vals.get(right)) == false){
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

## 方法二

将链表中后半部分的链表反转后，将其与前半部分的链表进行逐元素比较，最后再将后半部分的链表进行反转恢复。此方法可以将空间复杂度降到O(1)。

```java
// 方法二：后半链表反转
// 时间复杂度：O(n)
// 空间复杂度：O(1)，只需原地操作
class Solution {
    public boolean isPalindrome(ListNode head) {
        // 通过快慢指针找到链表的中间节点
        ListNode fast = head;
        ListNode slow = head;
        while(fast != null && fast.next != null){
            slow = slow.next;
            fast = fast.next.next;
        }

        // 反转后半部分的链表
        ListNode backHead = reverseList(slow);
        // 保存后半部分反转后的链表头节点
        ListNode backHeadTemp = backHead;
        ListNode frontHead = head;
        // 开始进行回文比较
        while(frontHead != null && backHead != null){
            if(frontHead.val != backHead.val){
		            // 小问题：如果不是回文，就直接返回，会导致后面恢复链表的操作没执行，见改进版
                return false;
            }
            frontHead = frontHead.next;
            backHead = backHead.next;
        }

        // 比较完成之后将链表恢复，但逻辑还不是很清晰，见改进版
        reverseList(backHeadTemp);

        return true;
    }

    // 反转链表
    public ListNode reverseList(ListNode head) {
        ListNode cur = head;
        ListNode pre = null;
        while(cur != null){
            ListNode temp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = temp;
        }
        return pre;
    }
}

// 方法二（改进）
class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // 1. 找到前半部分链表的尾节点 (快慢指针)
        ListNode firstHalfEnd = endOfFirstHalf(head);
        // 2. 反转后半部分链表
        ListNode secondHalfStart = reverseList(firstHalfEnd.next);

        // 3. 判断是否回文
        ListNode p1 = head;
        ListNode p2 = secondHalfStart;
        boolean result = true;
        while (result && p2 != null) {
            if (p1.val != p2.val) result = false;
            p1 = p1.next;
            p2 = p2.next;
        }

        // 4. 还原链表（面试加分项：不破坏原数据结构）
        firstHalfEnd.next = reverseList(secondHalfStart);
        
        return result;
    }

    // 快慢指针找中点
    private ListNode endOfFirstHalf(ListNode head) {
        ListNode fast = head;
        ListNode slow = head;
        while (fast.next != null && fast.next.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }
        return slow;
    }

    // 经典的反转链表模板
    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }
}
```
