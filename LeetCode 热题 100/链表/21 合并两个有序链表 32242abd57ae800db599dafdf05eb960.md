# 21. 合并两个有序链表

[https://leetcode.cn/problems/merge-two-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/merge-two-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一：递归

递归需要经历一下两步：1. 将递归函数抽象化；2. 设置终止条件；3. 设置递归逻辑。先看第1步，将本题的mergeTwoLists函数抽象化解释就是合并两个链表，并返回合并后链表的头结点，而且过程中不产生任何新节点。接着到第2步，终止条件就是当某一链表递归到结尾null，此时直接返回另一个链表当前遍历到的结点。最后到第3步，假设当链表1的节点值小于链表2的节点值时，就去递归，将链表1除当前结点外的后续节点和链表2含当前结点开始的后续结点，合并完成后，根据第1步的定义，递归函数会返回合并后链表的头结点，此时将链表1的当前结点去接上这个头结点，最后将链表1的当前结点向上层返回，而上层继续接住这个链表1的当前结点，最后返回的就是合并好的链表的头结点。

```
// 方法一：递归
// 时间复杂度：O(m+n)
// 空间复杂度：O(m+n)
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // 设置边界条件
        if(list1 == null){
            return list2;
        }

        if(list2 == null){
            return list1;
        }

        // 开始递归合并函数
        if(list1.val >= list2.val){
            // 保持当前list2的节点不动，去合并当前list1和list2.next后续节点
            list2.next = mergeTwoLists(list1, list2.next);
            return list2;
        }else{
            // 同理
            list1.next = mergeTwoLists(list1.next, list2);
            return list1;
        }
    }
}
```

## 方法二：迭代

新建一个链表头指针和尾指针，然后循环比较两个链表的结点，将值较小的结点通过尾插法加入到新建的链表当中。循环结束后记得处理原链表的剩余节点。

```java
// 方法二：迭代
// 时间复杂度：O(m+n)
// 空间复杂度：O(1)
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode Curr1 = list1;
        ListNode Curr2 = list2;

        // 新建一个头结点和尾结点
        ListNode newListHead = new ListNode(-1, null);
        ListNode newListTail = newListHead;

        // 循环将两个链表的结点通过尾插法进行插入
        while(Curr1 != null && Curr2 != null){
            if(Curr1.val >= Curr2.val){
                ListNode temp = Curr2.next;
                Curr2.next = newListTail.next;
                newListTail.next = Curr2;
                Curr2 = temp;
                newListTail = newListTail.next;
            }else{
                ListNode temp = Curr1.next;
                Curr1.next = newListTail.next;
                newListTail.next = Curr1;
                Curr1 = temp;
                newListTail = newListTail.next;
            }
        }

        // 处理每个链表可能剩余的结点
        while(Curr1 != null){
            ListNode temp = Curr1.next;
            Curr1.next = newListTail.next;
            newListTail.next = Curr1;
            Curr1 = temp;
            newListTail = newListTail.next;
        }

        while(Curr2 != null){
            ListNode temp = Curr2.next;
            Curr2.next = newListTail.next;
            newListTail.next = Curr2;
            Curr2 = temp;
            newListTail = newListTail.next;
        }

        return newListHead.next;
    }
}
```
