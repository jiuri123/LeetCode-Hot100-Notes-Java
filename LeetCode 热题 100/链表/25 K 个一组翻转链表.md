# 25. K 个一组翻转链表

[https://leetcode.cn/problems/reverse-nodes-in-k-group/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/reverse-nodes-in-k-group/description/?envType=study-plan-v2&envId=top-100-liked)

思路不难，不涉及比较复杂的算法，但是过程比较复杂，容易出错，所以面试的时候最好还是画图，不要在脑子里面想。具体思路就是将原链表划分成多个子链表，然后依次翻转每个子链表。翻转前还需要先判断这个子链表的结点个数是否大于等于k，这个判断的过程也可以顺便记录一下该子链表的尾结点和下一子链表的头结点，方便后续的翻转。

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 设置虚拟头结点
        ListNode fakeHead = new ListNode(-1, head);
        ListNode curFakeHead = fakeHead;

        while(true){
            int count = 0;
            // 找到当前需反转子链表的尾结点
            ListNode curTail = curFakeHead;
            while(curTail.next != null && count != k){
                count++;
                curTail = curTail.next;
            }

            // 如果不足k，则保持剩余节点的原有顺序
            if(count != k){
                break;
            }

            // 记录反转链表后的尾结点
            ListNode afterReverseTail = curFakeHead.next;
            // 记录下一个子链表的头结点（注意，不是虚拟头结点）
            ListNode nextHead = curTail.next;
            // 开始反转链表逻辑
            ListNode pre = null;
            ListNode cur = curFakeHead.next;
            while(cur != nextHead){
                ListNode temp = cur.next;
                cur.next = pre;
                pre = cur;
                cur = temp;
            }
            // 将反转后子链表的尾结点指向下一子链表的头结点
            afterReverseTail.next = nextHead;
            // 反转前curTail是当前子链表的尾结点，反转后变成子链表的头结点了
            // 这里是将反转前子链表的虚拟头结点指向反转后子链表的头结点
            curFakeHead.next = curTail;
            // 准备开始下一子链表的反转
            // afterReverseTail表示下一子链表的虚拟头结点
            curFakeHead = afterReverseTail;
        }

        return fakeHead.next;
    }
}
```
