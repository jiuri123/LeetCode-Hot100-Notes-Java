# 146. LRU 缓存

[https://leetcode.cn/problems/lru-cache/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/lru-cache/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一（不推荐）

直接使用LinkedHashMap，LinkedHashMap的内部实现是哈希表+双向链表的结构，可以实现`get` 和 `put` 以 `O(1)` 的平均时间复杂度运行。

```java
import java.util.LinkedHashMap;
import java.util.Map;

/**
 * LRU 缓存实现，继承自 LinkedHashMap。
 * LinkedHashMap 内部维护了一个双向链表，可以保存元素的插入顺序或访问顺序。
 */
class LRUCache extends LinkedHashMap<Integer, Integer> {
    // 缓存的最大容量
    private int capacity;

    /**
     * 构造函数
     * @param capacity 指定缓存容量
     */
    public LRUCache(int capacity) {
        /**
         * 调用父类 LinkedHashMap 的构造函数：
         * initialCapacity: 初始容量
         * loadFactor: 负载因子，默认 0.75
         * accessOrder: 
         * - false (默认): 基于插入顺序排序
         * - true: 基于访问顺序排序（这是实现 LRU 的关键！）
         * 当我们调用 get() 或 put() 时，被访问的元素会被移动到链表的末尾。
         */
        super(capacity, 0.75F, true);
        this.capacity = capacity;
    }

    /**
     * 获取缓存数据
     * @param key 键
     * @return 如果存在返回 value，否则返回 -1
     */
    public int get(int key) {
        // 使用父类的 getOrDefault，如果 key 不存在则返回 -1
        // 由于 accessOrder 为 true，此操作会将该 key 移动到链表末尾（表示最近访问过）
        return super.getOrDefault(key, -1);
    }

    /**
     * 插入或更新缓存数据
     * @param key 键
     * @param value 值
     */
    public void put(int key, int value) {
        // 直接调用父类的 put 方法
        super.put(key, value);
    }

    /**
     * 这是一个钩子方法（Hook），在每次调用 put() 或 putAll() 后会被自动调用。
     * 它的返回值决定了是否要移除最“老”的节点。
     * * @param eldest 链表中最久未被使用的节点（头节点）
     * @return 如果返回 true，则删除该最老节点
     */
    @Override
    protected boolean removeEldestEntry(Map.Entry<Integer, Integer> eldest) {
        // 当当前 Map 的大小超过了预设的容量时，返回 true 以触发自动删除
        return size() > capacity; 
    }
}
```

## 方法二（面试推荐）

手动实现一个LinkedHashMap，因此内部需要维护一个哈希表和一个双向链表，哈希表实现了快速查找和插入，而双向链表实现了LRU的功能。

```java
class LRUCache {
    // 定义双向链表节点
    class Node {
        int key, value;
        Node prev, next;
        Node() {}
        Node(int k, int v) { key = k; value = v; }
    }

    private Map<Integer, Node> cache = new HashMap<>();
    private int size;
    private int capacity;
    private Node head, tail; // 虚拟头尾节点，简化删除逻辑

    public LRUCache(int capacity) {
        this.size = 0;
        this.capacity = capacity;
        // 初始化虚拟节点
        head = new Node();
        tail = new Node();
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        if(!cache.containsKey(key)){
            return -1;
        }else{
            Node node = cache.get(key);
            moveToHead(node);
            return node.value;
        }
    }

    public void put(int key, int value) {
        if(cache.containsKey(key)){
            Node node = cache.get(key);
            node.value = value;
            moveToHead(node);
        }else{
            Node newNode = new Node(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
            size++;
            if(size > capacity){
                Node oldestNode = removeTail();
                cache.remove(oldestNode.key);
                size--;
            }
        }
    }

    // --- 以下是辅助链表操作 ---
    private void addToHead(Node node) {
        node.next = head.next;
        head.next.prev = node;
        node.prev = head;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private Node removeTail() {
		    // 注意是 tail.prev 而不是 tail
		    // 因为 tail 是虚拟尾结点
        Node res = tail.prev; 
        removeNode(res);
        return res;
    }
}
```
