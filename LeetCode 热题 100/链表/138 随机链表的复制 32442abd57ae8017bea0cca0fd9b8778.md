# 138. 随机链表的复制

[https://leetcode.cn/problems/copy-list-with-random-pointer/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/copy-list-with-random-pointer/description/?envType=study-plan-v2&envId=top-100-liked)

本题next指针的复制很简单，但是random指针的复制就没那么简单了，因为所指向的结点在链表中的随机位置。因此问题的关键需要从查找入手，即查找新节点的random指针所指向的那个结点到底在新链表中的哪个位置。如果从头开始找，可能要遍历所有节点，时间复杂度较高。而在算法中要想降低查找的时间复杂度，可以给要查找的目标建立索引，索引的建立可以使用哈希表（方法一），或者自己手动建立（方法二）。

## 方法一：哈希表

使用一个哈希表先建立旧节点到新节点的映射（想象一下，相当于是每个旧节点都多了一个指针指向新链表中对应复制位置的新节点，只不过这个“指针”的实现是通过哈希表映射来实现的）。此时新链表的新节点已经全部新建完毕，并被旧节点所指向（哈希表映射），但`next`指针和`random`指针还是空的。此时重新遍历旧链表，然后通过哈希表来构建新链表中每个节点的`next`指针和`random`指针。

```java
// 方法一：哈希表
// 时间复杂度：O(N)
// 空间复杂度：O(N)
class Solution {
    public Node copyRandomList(Node head) {
        if(head == null){
            return null;
        }

        // 存储旧节点到新节点的映射
        Map<Node, Node> map = new HashMap<>();
        Node curr = head;
        while(curr != null){
            map.put(curr, new Node(curr.val));
            curr = curr.next;
        }

        // 构建新节点的next和random的指向
        curr = head;
        while(curr != null){
		        // 经过get之后，得到的是新节点
            map.get(curr).next = map.get(curr.next);
            map.get(curr).random = map.get(curr.random);
            curr = curr.next;
        }

        return map.get(head);
    }
}
```

这里就是给新节点的random指针所指向的那个结点建立索引，即放到哈希表中，进而减少查找的时间复杂度。

## 方法二（面试推荐）：拼接+拆分

将旧节点复制后的每个新节点插入到对应每个旧节点的后面，然后更新每个新节点的random指针，最后再将新旧链表进行拆分即可。

```java
// 方法二：拼接+拆分
// 时间复杂度：O(N)
// 空间复杂度：O(1)
class Solution {
    public Node copyRandomList(Node head) {
        if(head == null){
            return null;
        }

        // 拼接新旧链表：将每个新节点插入到每个对应旧节点的后面
        Node curr = head;
        while(curr != null){
            Node newNode = new Node(curr.val);
            newNode.next = curr.next;
            curr.next = newNode;
            curr = newNode.next;
        }

        // 构建新节点的random指向
        curr = head;
        while(curr != null){
            if(curr.random != null){
                curr.next.random = curr.random.next;
            }
            curr = curr.next.next;
        }

        // 拆分新旧链表
        curr = head.next.next;
        Node newHead = head.next;
        Node newTail = head.next;
        Node oldTail = head;
        while(curr != null){
            oldTail.next = curr;
            oldTail = oldTail.next;
            newTail.next = curr.next;
            newTail = newTail.next;
            curr = newTail.next;
        }
        // 单独处理旧链表的最后一个节点的next指向
        oldTail.next = null;
        return newHead;
    }
}
```

这里其实也是给每个新节点建立索引，只不过这里直接使用了旧节点的next指针来建立索引，节省了空间。而上一题是使用哈希表来建立索引。其实本质上都是将旧节点指向其所复制后的新节点，由此来建立新节点的索引，方便查找。
