# 287. 寻找重复数

[https://leetcode.cn/problems/find-the-duplicate-number/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/find-the-duplicate-number/description/?envType=study-plan-v2&envId=top-100-liked)

将这些数字和其下标看做链表，因为重复的数会被两个不同的下标所指向，因此重复的数就是该链表中环的入口。因此只需要找到环的入口，就找到了重复的数。

```java
class Solution {
    public int findDuplicate(int[] nums) {
        // 利用快慢指针找到环内的相遇点
        int slow = 0;
        int fast = 0;
        do{ 
            slow = nums[slow]; // 慢指针走一步
            fast = nums[nums[fast]]; // 快指针走两步
        }while(slow != fast);

        int temp1 = 0; // 一个指针从起点开始
        int temp2 = fast; // 另一个指针从相遇点开始
        while (temp1 != temp2) { // 各走一步，直到相遇
            temp1 = nums[temp1];
            temp2 = nums[temp2];
        }

        return temp1; // 返回相遇点，就是重复的数
    }
}
```
