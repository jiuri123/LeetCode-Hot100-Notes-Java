## **方法二：排序**

```java
class Solution {
    public int majorityElement(int[] nums) {
        Arrays.sort(nums);
        return nums[nums.length / 2];
    }
}
```

## 方法三：摩尔投票法（同归于尽法，面试推荐）

```java
class Solution {
    public int majorityElement(int[] nums) {
        int count = 0; // 记录目前擂台上的人数（都是同一类人）
        Integer candidate = null; // 记录擂台上那帮人是什么人
        for(int num : nums){
            if(count == 0){ // 若擂台上没人，则这个人直接上擂台
                candidate = num;
                count++;
                continue;
            }else if(num == candidate){ // 若擂台上有人，但是是自己人
                count++; // 记录台上人数
            }else{ // 若擂台上有人，但不是自己人
                count--; // 同归于尽
            }
        }
        return candidate;
    }
}
```
