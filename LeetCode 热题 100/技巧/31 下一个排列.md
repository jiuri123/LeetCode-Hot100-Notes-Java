# 31. 下一个排列

[https://leetcode.cn/problems/next-permutation/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/next-permutation/description/?envType=study-plan-v2&envId=top-100-liked)

想要找到下一个更大的排列，我们需要**尽可能保持左边的位不动，然后从右往左找到第一个向右升序的数字（即这个数字的右边到序列结尾是一个降序序列），并在这个降序序列中找到第一个比它大的数字来替换它（这样可以使得整体序列微微增加），然后将这个改变后的降序序列进行升序排列以保证整体的增量最小（这样可以使得整体序列增加最小）。**

可以将序列想象成一个数字，从右到左分别是个位、千位、百分位……因此目标就变成了交换其中的两个数，使得新数字比原来的数字大一捏捏。因此尽量保持高位不动（因为高位动一下就是几万几千的变化），而是先去动低位的数字。具体做法就是从右往左……（待补充）

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        if(nums == null || n <= 0) return;

        // 1. 从后往前寻找第一个相邻升序对 (i, i+1)
        int i = 0;
        for(i = n - 2; i >= 0; i--){
            if(nums[i] < nums[i + 1]){
                break;
            }
        }

        // 2. 如果找到了 (i >= 0)，说明不是最大的排列
        int j = 0;
        if(i >= 0){ 
            // 从后往前寻找第一个比 nums[i] 大的数
            for(j = n - 1; j >= i + 1; j--){
                if(nums[j] > nums[i]){
                    break;
                }
            }
            // 交换 i 和 j
            swap(nums, i, j);
        }

        // 3. 反转 i 之后的序列 (使其从降序变升序)
        // 如果 i < 0，说明整个数组是降序的，反转后变为最小排列
        reverse(nums, i + 1, n - 1);
    }

    public void swap(int[] nums, int i, int j){
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    public void reverse(int[] nums, int left, int right){
        while(left < right){
            swap(nums, left, right);
            left++;
            right--;
        }
    }
}
```
