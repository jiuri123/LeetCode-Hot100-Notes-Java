# 295. 数据流的中位数

[https://leetcode.cn/problems/find-median-from-data-stream/description/?envType=study-plan-v2&envId=top-100-liked](https://leetcode.cn/problems/find-median-from-data-stream/description/?envType=study-plan-v2&envId=top-100-liked)

## 方法一

**💡 核心思路**
为了在 O(1) 的时间内找到中位数，我们需要将数据流分成左右两部分：
1. **左半部分（较小的一半）：** 使用一个 **大顶堆（Max-Heap）** 存储。堆顶是左半部分的最大值。
2. **右半部分（较大的一半）：** 使用一个 **小顶堆（Min-Heap）** 存储。堆顶是右半部分的最小值。
**维护规则：**
• 左半部分的元素个数等于右半部分，或者比右半部分多一个。
• 这样，如果总数是奇数，中位数就是大顶堆的堆顶。
• 如果总数是偶数，中位数就是两个堆顶元素的平均值。

```java
class MedianFinder {
    // 大顶堆，存储较小的一半元素
    private PriorityQueue<Integer> leftMaxHeap;
    // 小顶堆，存储较大的一半元素
    private PriorityQueue<Integer> rightMinHeap;

    public MedianFinder() {
        // Java 默认是小顶堆，大顶堆需要使用 Comparator.reverseOrder()
        leftMaxHeap = new PriorityQueue<>((a, b) -> b - a);
        rightMinHeap = new PriorityQueue<>();
    }
    
    public void addNum(int num) {
        // 核心步骤：
        // 1. 先将新数放入大顶堆（左边）
        leftMaxHeap.offer(num);
        
        // 2. 为了保证平衡，将大顶堆的最大值弹出并压入小顶堆（右边）
        rightMinHeap.offer(leftMaxHeap.poll());
        
        // 3. 如果右边比左边多，则送回一个给左边，
        // 确保 leftMaxHeap.size() >= rightMinHeap.size()
        if (rightMinHeap.size() > leftMaxHeap.size()) {
            leftMaxHeap.offer(rightMinHeap.poll());
        }
    }
    
    public double findMedian() {
        if (leftMaxHeap.size() > rightMinHeap.size()) {
            // 奇数情况：左边堆顶即为中位数
            return (double) leftMaxHeap.peek();
        } else {
            // 偶数情况：两边堆顶相加除以 2
            return (leftMaxHeap.peek() + rightMinHeap.peek()) / 2.0;
        }
    }
}
```
