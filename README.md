# LeetCode 热题 100 题解笔记（Java）

本仓库收录了 LeetCode 热题 100 的完整题解笔记，使用 Java 语言编写，按算法类型分类整理。

## 目录结构

| 分类 | 说明 |
|------|------|
| 哈希 | 两数之和、字母异位词分组、最长连续序列 |
| 双指针 | 移动零、盛最多水的容器 |
| 滑动窗口 | 无重复字符的最长子串、找到字符串中所有字母异位词 |
| 子串 | 和为 K 的子数组 |
| 普通数组 | 缺失的第一个正数、轮转数组、除了自身以外数组的乘积 |
| 矩阵 | 矩阵置零、搜索二维矩阵 II |
| 链表 | 两数相加、合并两个有序链表、合并 K 个升序链表、相交链表、环形链表、回文链表、K 个一组翻转链表、随机链表的复制、LRU 缓存、排序链表 |
| 二叉树 | 二叉树展开为链表、二叉树中的最大路径和、二叉树的右视图、二叉搜索树中第 K 小的元素、路径总和 III |
| 图论 | 岛屿数量、课程表、实现 Trie (前缀树)、腐烂的橘子 |
| 回溯 | 括号生成、单词搜索 |
| 二分查找 | 寻找两个正序数组的中位数、搜索旋转排序数组、搜索二维矩阵 |
| 栈 | 最小栈、字符串解码 |
| 堆 | 数据流的中位数 |
| 动态规划 | 乘积最大子数组、最长有效括号 |
| 多维动态规划 | 最小路径和 |
| 技巧 | 多数元素、下一个排列、寻找重复数 |

## 使用方式

每个分类文件夹下包含对应题目的 Markdown 笔记，部分题目配有图解说明。可直接在 GitHub 上浏览阅读，或 clone 到本地查看。

```bash
git clone https://github.com/jiuri123/LeetCode-Hot100-Notes-Java.git
```
